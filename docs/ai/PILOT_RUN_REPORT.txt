РЕШЕНИЕ ВЛАДЕЛЬЦА
Для первого пилота обязательного преподавателя нет. Проверка, подсказки,
оценка и прогресс автоматические. Пользователь подтвердил любые учебные темы.

РЕАЛИЗОВАНО
- Взят принятый source209 другого агента в отдельной Git worktree; предыдущие
  source191, source209, архивы, базы и незакоммиченные изменения сохранены.
- Личные TXT/PDF/DOCX/PPTX, ограниченное локальное извлечение, предпросмотр
  и явный диапазон100–6000 символов. Нет embedding/RAG/новых весов/платногоAPI.
- Очередь SQLite; durable request_id до dispatch; восстановление только по
  receipt. Повтор/сбой не запускает неизвестную генерацию ещё раз.
- Локальный ИИ создаёт один краткий урок и три MCQ либо только тест;
  точные цитаты ограничены подстроками документа. Второй слепой проход той
  же модели сверяет ключи/однозначность. Это коррелированная автопроверка.
- Неоднозначные/неподтверждённые ключи блокируют набор. Подсказка, признанная
  раскрывающей ответ, заменяется нейтральным советом, без подмены ключа.
- Сервер автоматически считает баллы по ключам ИИ. Повторы идемпотентны;
  последнее решение каждого вопроса заменяет прежний балл. Полный выбранный
  учебный текст доступен перед тестом, поскольку краткий урок бывает неполон.
- Проверенные сервером auto_checked попытки Python открывают дальнейшие
  подсказки без человека; provenance/рубрика/digest/evidence/балл проверяются.
- README-PILOT, requirements, SETUP/START/CREATE_PILOT_ADMIN, launcher и
  source-only упаковщик с проверкой SHA256 каждой записи.
