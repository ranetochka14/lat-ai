Запуск: START_MAIN.cmd. Он запускает Django, приватный ИИ worker, обработчик очереди документов и сайт. Остановка: Ctrl+C в окне запуска. Для интерфейса без модели: START_MAIN.cmd -WithoutModel.
Сайт: http://127.0.0.1:5173/#/courses
Документы: http://127.0.0.1:5173/#/documents
Django admin: http://127.0.0.1:8000/admin/

На компьютере владельца .runtime/main-local.json указывает существующую БД и зависимости. Этот файл содержит локальные пути и не входит в source-архив. Не удаляйте и не меняйте его при обновлении: неверный runtime означает другую БД. Скрипт откажется запускать настроенный существующий runtime без django.sqlite3. Для проверки выбора путей: START_MAIN.cmd -CheckOnly.

На новом компьютере выполните SETUP_PILOT.cmd; при отсутствии локальной конфигурации START_MAIN использует .venv, установленный Node и .runtime/i02. LM Studio и существующая модель Qwen3.5-9B должны быть подготовлены отдельно, новые веса скрипт не скачивает. requirements.txt находится в корне. CREATE_PILOT_ADMIN.cmd относится к отдельному pilot runtime; для MAIN создавайте администратора через выбранный Python и tools/pilot.py с тем же явным --runtime, командой manage createsuperuser.

START_AI_REVIEW.cmd и START_PILOT.cmd сохранены для совместимости: первый исторический, второй по умолчанию использует отдельную .runtime/pilot. Они не являются актуальной точкой запуска MAIN. Не запускайте их одновременно с MAIN на тех же портах. START-FULL относится к иному историческому профилю и для этой работы не нужен.

Включено: evidence-v3e-context, приватный /assess/receipt, автоматические оценки/прогресс Python, проверка оснований для подсказок после auto_checked; DOC01 с личными документами, очередью и автотестами. Учебный пакет 50 уроков пока не импортирован.

Разбор ответов: варианты теста выровнены в кликабельные строки. После ответа показаны выбранный вариант, верный вариант и разбор; цитата раскрывается отдельно. Отчёт Python разделён на балл, зачтённые критерии и критерии, которые нужно уточнить. Баллы и прогресс считаются по прежним правилам.

Новые тесты по документам получают отдельный разбор каждого варианта. Подсказка исключает один неверный вариант и объясняет причину; остальные три остаются для самостоятельного выбора. Подсказка проходит проверку перед публикацией. Если подходящего разбора нет или проверка его отклонила, приложение сообщает о недоступности подсказки. Сохранённые ранее тесты автоматически не переписываются: для новых объяснений и подсказок создайте новый тест из того же документа. Старые попытки и баллы сохраняются.

Ограничения: несколько проходов одной модели не гарантируют правильную оценку; U02/V05/U46 остаются известными проблемами. Незавершённая Python-оценка не повторяется автоматически; worker receipt не означает готового восстановления Django. Прогресс документов отдельный. Оценка не требует преподавателя. Профиль чужого ПК 60/70/80 и эксперимент SDK load/abort не активированы. RAG и платного API нет.

История, offline-инструменты и открытые задачи: в ветке archive: https://github.com/ranetochka14/lat-ai/tree/archive/snapshots/main-3dacd7d/docs/ai/INTEGRATED_WORK.txt. Canonical roadmap и единственный STATUS остаются в исходном проекте. Не считайте архивные STATUS отдельным текущим журналом.
