# LAT AI — дополнение контекста цитат и границы валидации

Уточнение 11.11: H01–H32 и V01–V32 — разные авторские наборы. Первичные
результаты соответственно26/0/6 и25/1/6 (верные/неверные/отказы), joint26 и24.
Пересчёта одного набора в другой не было; одинаковое имя «новый32» было
неудачным. SHA и разбор: `outputs/ai-pilot-integrity-2026-11-11/ERRATA_DATASETS.txt`.
Replay160 —160 разных известных текстов, исторические48 повторов —8 текстов×6.
Новая техническая проверка инструмента на V11/U02×3 дала V11 верный3/3 и
U02 заниженный3/3 вместо прежних отказов. Нулевая нестабильность внутри этих
трёх серий не означает правильность или постоянную воспроизводимость.
Промпты, рубрики и решения после наблюдения не подстраивались.

Текущая ревизия `2026-11-11-evidence-v3e-context` дополнительно распознаёт
явную запись `x := 2` и исключает десятичные значения вроде `x = 2.5` из
поиска контекста x=2. На 160 известных сохранённых результатах checks не
изменились; дополнена только цитата V11. Это regression replay, не новый
holdout. Живые V11/N05 прошли 2/2 с полными цитатами и точным чтением квитанций.
Промпты, критерии, два модельных прохода и правило согласия прежние.
Недооценка V05 и отказы на правильных U02/U26/H18 остаются открытыми.

Отдельный ZIP пилота/ручной проверки и отчёт находятся в рабочей области:
`outputs/ai-continuation-2026-11-11/`. Экспорт для двух разметчиков исключает
модельные результаты и авторские метки. Заморозка сохраняет исходные
разметки с SHA; согласованные checks при ambiguous_rubric=true также требуют
ручного разрешения. Реальных работ и подписанных решений пока нет.
Ниже сохранены метод и результаты предыдущей ревизии.

Ревизия `2026-11-11-evidence-v3d-context` сохраняет два модельных прохода,
промпты, рубрики критериев и правило согласия из [evidence-v2h](ASSESSMENT_EVIDENCE_V2.md). Изменяется
только формирование двух составных цитат для существующего `L1.condition.1`.

Для положительного первого критерия цитата дополняется фрагментом с явным
значением x=2, если его не было в цитате и в исходном ответе найден ровно
один подходящий фрагмент. Сравнение x==2 не принимается за присваивание.
Для положительного второго критерия аналогично добавляется однозначный
фрагмент с отсутствующим именем ветки if или else. Берётся минимальный
непрерывный диапазон исходного ответа, а не весь ответ и не пересказ.

Это структурное дополнение контекста, НЕ детерминированный судья истинности.
При неоднозначных совпадениях ничего не угадывается. Отрицательные checks
остаются отрицательными с пустой цитатой. Два прохода могут одинаково ошибаться;
добавление контекста не исправляет их оценку и не служит новым независимым голосом.

В replay128 прежних результатов checks не изменились ни в одном случае,
изменились только две неполные цитаты N05/U15. Replay не является новым
модельным прогоном. Экспериментальные новые промпты A/B дали регрессии и
не внедряются. Отказы U02/U26/H18 остаются нерешённой задачей; их нельзя
скрывать заменой на автоматически положительный балл.

Реальные результаты стабильности, нового frozen32 и интервалы находятся в
`outputs/assessment-v3-2026-11-11/REPORT.txt` рабочей области. Односторонняя
95% биномиальная граница — лишь условный расчёт для независимой выборки:
синтетика, настройка и повтор одного ответа не доказывают качество на учениках.

Теневой пилот подготовлен отдельно. Нужны реальные обезличенные работы,
два независимых разметчика, разрешение разногласий и заранее утверждённые
границы ошибки/отказов. Результаты пилота не записываются в Django и не
показываются ученикам. Всего3 серии: первая первичная, две дополнительные;
повторы анализируются отдельно и не увеличивают число независимых работ.

Публичный формат и лимиты не меняются. Диагностика причин и времени стадий
доступна в offline `tools/evaluate-assessment-shadow.mjs` рабочей области.
Приватный AI receipt API описан в `ASSESSMENT_RECEIPT.md`; применение его
backend/frontend и пользовательская очередь ручной проверки ещё не реализованы.
