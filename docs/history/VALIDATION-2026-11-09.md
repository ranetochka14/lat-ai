# Проверка LAT AI

Дата: 9 ноября 2026 года.

## Что проверено

- **Microsoft Edge, настольный экран:** главная страница, навигация и экран каталога без авторизации.
- **Мобильный экран 390 px:** главная и каталог, раскрытие меню; горизонтальная прокрутка не обнаружена.
- **Работа с API:** 15 автоматических контрактных проверок клиента — маршруты, поля регистрации, JWT, обновление токена, ошибки и безопасная пагинация.
- **Локальный сервер:** 11 проверок раздачи файлов, HTTP-методов и ограничения доступа к файлам внутри проекта.
- **Учебный сценарий в браузере:** вход → кабинет → курс → урок → отправка ответа со статусом «На проверке».
- **Документы и каталог:** поиск фрагмента документа, отсутствие результатов по фильтру курсов и очистка фильтра.
- **Ошибки:** понятное сообщение при недоступном API; отказ входа, если профиль не получен после выдачи токена.
- **Клавиатура:** ссылка «Перейти к содержимому» переводит фокус в основной блок, не меняя маршрут.
- **Шрифты:** Nunito Sans и Inter включены локально вместе с лицензиями OFL; наличие кириллицы проверено.

## Обновление оформления: вариант №5

- Главная заменена на кабинет с боковым меню, учебной иллюстрацией и пастельными карточками. Отдельный рекламный лендинг удалён.
- Композиция сверена с исходным макетом №5 в окне 1536×1024. Повторно проверен мобильный экран 390×844, включая раскрытие бокового меню; горизонтального переполнения страницы нет.
- Проверены вход, загрузка курсов/прогресса/ответов, поиск фрагментов и загрузка файла непосредственно на главной. Проверочные запросы отправлялись только изолированному QA-серверу.
- До входа карточки показывают пустые состояния; кнопка загрузки открывает форму входа. Тестовые аккаунты и курсы не встроены в приложение.
- Исправлена обработка завершения загрузки и поиска после ухода пользователя на другую страницу.
- Скриншот `LAT-AI-friendly-preview.jpg` показывает интерфейс на проверочных данных, а не содержимое рабочей базы.

## Условия проверки

После добавления анимаций повторно проверены переключение разделов и единственный индикатор активного пункта, открытие и смена форм входа/регистрации, закрытие крестиком и Escape, открытие мобильного меню и переход из него. Ошибок JavaScript в Edge не обнаружено. Учтён prefers-reduced-motion в CSS, включая фон модального окна, и в Web Animations API.

В Edge проверены обе формы, возврат фокуса после закрытия, фокус на первом поле после переключения, крестик, Escape и клик по фону. На экранах 390×844 и 390×480 форма остаётся доступной; при недостаточной высоте работает внутренняя прокрутка. При закрытии отправка формы блокируется. Код повторного открытия отменяет прежнее закрытие.

Повторная диагностика во встроенном браузере чата выявила `prefers-reduced-motion: reduce`: прежние проверки подтверждали работу форм, но движение было отключено настройкой системы. Добавлена настройка «Анимации» с режимами «Как в системе», «Включены» и «Без движения», сохранением в браузере и единым применением к CSS и JavaScript. Открытие окна теперь длится 600 мс, переход между формами — 320 мс, закрытие — 180 мс. В видимом браузере при включённых анимациях зафиксирован промежуточный кадр регистрации: opacity 0.398, scale 0.940, translateY 24.1 px; после завершения — opacity 1 и transform none. Повторный вход также показал промежуточный кадр. Проверены смена форм, Escape, режим без движения и сохранение выбора после обновления страницы.

На раннем этапе дизайна браузерный сценарий выполнялся с временным сервером контрактных проверок. Он не используется в текущем полном запуске и не входит в поставку. Приложение получает пользовательские данные из настроенного API.

## Подключение настоящего бэкенда

- Запущены предоставленный Django 5.2.19 на 127.0.0.1:8000 и отдельная PostgreSQL 16.15 с pgvector 0.8.6 на 127.0.0.1:55432. Все миграции применены, Django system check — без ошибок.
- После запуска повторно сверены все 55 Python-файлов бэкенда с извлечёнными исходниками: SHA256 совпали, исходники не редактировались. Настройки локального запуска задаются переменными окружения.
- Используется отдельная база `lat_ai_demo`. В ней созданы 4 курса, 12 уроков и заданий, 4 завершённых урока и 6 исходных примеров ответов. Через интерфейс отправлена дополнительная попытка: API подтвердил всего 7 ответов, из них 4 проверены и 3 на проверке.
- Во встроенном видимом браузере проверены вход Даны, реальная регистрация нового ученика, его пустой личный прогресс, выход и повторный вход, каталог, урок и отправка ответа. Авторизация выполняется через JWT предоставленного API.
- Через интерфейс загружен документ по алгебре. Автоматическая проверка добавила ещё два документа. Все 3 получили статус `ready`.
- Настоящая модель `intfloat/multilingual-e5-small` загружена из официального репозитория с проверкой контрольных сумм. Размерность векторов — 384; модель работает на CPU в локальном offline cache. Проверены 3 смысловых запроса, все нашли ожидаемые документы. Запрос из браузера про количество корней вернул фрагменты про дискриминант.
- Python-библиотеки из предоставленного архива восстановлены отдельно от чистого интерпретатора. Исходное виртуальное окружение не запускалось. Для новой установки есть локальный установщик и ограничения версий, соответствующие проверенному окружению.
- Полный повторный запуск через `tools/start-local.ps1 -NoBrowser` в Windows PowerShell 5.1 завершился успешно: миграции и seed не внесли дубликатов, 3 документа использованы повторно, все проверки API прошли. Браузерная консоль — без ошибок JavaScript.

ИИ-репетитор и полноценный кабинет преподавателя остаются возможностями в разработке в исходном бэкенде; интерфейс это отражает. Публичное размещение не выполнялось.
