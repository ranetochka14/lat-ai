# Проверки

Команды для проверки без модели находятся в [руководстве запуска](runbook.md#проверки-без-модели). Всегда используйте отдельный runtime. Успешные технические тесты не подтверждают правильность учебного содержания.

## Предыдущая публикация: 12.11.2026

На том этапе прошли 106 Node, 40 Django и 9 интерфейсных тестов: всего 155. Проверка `integration/ai/check.mjs` охватывала 3 схемы, 2 примера запросов, 6 ответов и 20 SHA ядра. Живых вызовов модели не было.

Django запускался через `tools/pilot.py` с отдельным `.runtime/publication-verify`, Python 3.12 из проверенного Windows-комплекта и отдельным каталогом зависимостей парсеров. Использовался Node 24.11.1. Первый Node-прогон завершился с EACCES на собственном loopback; после разрешения локального доступа прошли 106/106. Первый лог сохранён вместе с успешным повтором.

Тогда были изменены документация и SETUP: установка Node через `npm ci`, без подготовки отдельной pilot-БД, с указанием основного запуска. MAIN по-прежнему вызывает `prepare_safe` для выбранной БД. Полная установка на чистом Windows ещё не проверена.

## Проверки содержания и интерфейса

Это прежние испытания на синтетических материалах, а не новый прогон модели:

| Материал | Результат |
| --- | --- |
| SQL | Готовность за 44.422 с; 3/3 содержательные подсказки и 12/12 привязок объяснений. Неверный ответ получил 0/1, верный — 1/1. Повторное чтение результата стабильно. |
| Круговорот воды | Готовность за 34.328 с; 0/3 приемлемых подсказок. Модель назвала таяние противоположностью испарения и превратила «может» в обязательное условие. Повторная проверка той же моделью пропустила ошибку. |

Эти примеры не подтверждают готовность к любым учебным темам. В том испытании 21 таблица основной БД осталась прежней, прошли семь HTTP-проверок и проверок хешей. Это исторические результаты, а не проверка нынешней рабочей БД.

Выбор вариантов проверялся на широком и узком экранах, включая клавишу Down. Полная визуальная проверка и проверка соответствия WCAG не завершены. Старые 335 тестов ядра и другие счётчики относятся к своим отчётам; они не входят в новый итог.

## Сохранность архивов

При предыдущей передаче 4212 файлов сравнили по байтам и SHA256 с исходниками. Проверка искала признаки токенов, JWT, приватных ключей, настоящих адресов и паролей, бинарных баз, документов, весов и вложенных служебных инструкций. Исключений для публикации не обнаружено. Найденные аккаунты синтетические; метаданные содержат старые локальные пути и хеши секретов, но не их значения. Такая проверка не заменяет исчерпывающий ручной разбор каждого текста.

В чистом локальном клоне коммита `8b06a4a` выгрузились все 4470 файлов. Все 4212 файлов с зафиксированным происхождением совпали по SHA256 и Git blob. `npm ci` установил 5 пакетов по lockfile через официальный registry: локального кеша было недостаточно. В клоне повторно прошли 20 SHA со схемами и 9 интерфейсных тестов. Полный Node/Django-прогон выполнялся в исходной копии. Клонирование на машине разработки не равно установке на чистом Windows.

Архивные логи сохраняются в [ветке archive](https://github.com/ranetochka14/lat-ai/tree/archive). Историческая проверка архива сверяла манифест с Git index после staging, а также исключение runtime, весов, баз и символьных ссылок. Рабочие данные и секреты в коммиты не входят. Атрибут `integration/ai/core/** -text` сохраняет байты закреплённого ядра.

Прежний локальный просмотр исходников, архивов и инструкций не нашёл блокирующих замечаний. Обсуждение краткого описания процедуры без кода и логов не было независимым аудитом. Проверка качества ответов и переносимости всё ещё нужна; обязательное подтверждение каждого результата преподавателем в платформе не предусмотрено.
