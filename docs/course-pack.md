## Состав и границы

- 2 курса: Python — 20 уроков, математика — 30. Теория, примеры и самостоятельная практика находятся в тексте уроков.
- 4 файла ключей ответов и рекомендации для ИИ не попадают в БД, публичные assets или промпты.
- Новые задания автопроверки не создаются: текущая Python-оценка привязана к четырём исходным упражнениям, а ключи пакета не являются готовыми рубриками. Баллы, попытки и прогресс не имитируются.
- Исходный ZIP неизменен. Импортёр содержит 7 точечных уточнений: Unicode-имена, округление `//`, цепочка `if/elif`, второй элемент с повторениями, условие `n > 1`, область вероятностной модели, геометрическая задача о лестнице. Заголовки берутся из H1 уроков: 19 отличаются от каталога, включая потерянные «ё» и пунктуацию.
- README пакета устарел (версия 1.0, 10/15 уроков); каталог версии 3.0 и реальные 20/30 файлов согласованы. Глубина теории неравномерна. Это техническая и содержательная проверка, не подтверждение соответствия всей школьной программе.

## Установка в выбранный локальный пилот

Проверенные публичные тексты теперь входят в `backend/courses/data/school-courses-v3.json`.
ZIP и ключи ответов для установки не нужны. SHA файла проверяется до записи.
Курсы становятся видны всем пользователям этого пилота после входа в каталог.

Остановите свой пилот перед обслуживанием. Используйте тот же runtime, который показывает
`START_MAIN.cmd -CheckOnly`. Команда не запускает модель и не выполняет миграции:

```powershell
python -X utf8 -B tools/pilot.py --runtime <runtime-вашего-пилота> manage install_school_courses --backup-dir <новая-папка-вне-runtime>
```

Для нового пилота сначала выполните `tools/pilot.py --runtime <новый-runtime> prepare`.
Перед импортом сохраняется согласованная SQLite-копия и проверяется её целостность.
Два курса и 50 уроков добавляются одной транзакцией. Повторная установка сохраняет ID;
если совпавший по имени курс или урок редактировался, вся операция прекращается без перезаписи.
Существующие упражнения, попытки, документы и прогресс не заменяются. Итог и SHA резервной
копии записываются в `installation.json` рядом с ней. Эту папку не публикуйте: БД содержит
учётные записи и пользовательские данные. Импорт не обновляет изменённые уроки автоматически.

Практика этих 50 уроков остаётся самостоятельной, внутри учебных текстов. Автоматические
баллы за неё не создаются. Четыре прежних упражнения с ИИ-проверкой сохраняются отдельно.

## Воспроизведение без действующей БД

Использовать Python 3.12 с установленными зависимостями пилота. ZIP остаётся вне репозитория. Команды из корня репозитория:

```powershell
python -X utf8 -B tools/import-course-pack.py <путь-к-ZIP> --report <новый-check.json>
python -X utf8 -B tools/import-course-pack.py <путь-к-ZIP> --runtime .runtime/course-pack-preview --report <новый-import.json>
python -B tools/pilot.py --runtime .runtime/course-pack-preview --api-port 8003 --site-port 5177 --worker-port 8375 run
```

Импорт разрешён только в **новый** `.runtime/course-pack-*` этого checkout. Любой существующий каталог или отчёт отклоняется. После сбоя каталог и отчёт сохранить; не удалять его для автоматического повтора. Подготовка создаёт синтетического review-пользователя и исходный демонстрационный курс. Два новых курса создаются одной транзакцией, без обновления/удаления прежних строк. Итого 3 курса, 52 урока и 4 прежних упражнения.

Сайт: `http://127.0.0.1:5177/#/courses`. В настройках профиля → «Подключение к платформе» указать `http://127.0.0.1:8003/api/v1`, затем войти: `review@lat-ai.local` / `LatAI-Review-2026!`. Это локальный синтетический аккаунт. Порт сайта сам не переключает API.

Модель не включать: для чтения курсов она не нужна. Существующие стенды и их runtime не использовать. Новый frontend поддерживает безопасное подмножество Markdown: заголовки, списки, выделение и код; HTML, изображения и активные ссылки из материала не исполняются.
