# Точка продолжения — 12 ноября 2026

Интегрированная версия LAT AI для локального пилота. База ветки — `ranetochka14/lat-ai`, commit `b4fd637`; I02–MAIN01–DOC01–UX01 собраны поверх исходного прототипа. Интеграцию заново не начинать. Форк и PR предназначены для совместной разработки, не означают готовность к публичному развёртыванию.

## Что решено

- Django проверяет пользователя и доступ; Node worker имеет приватный IPC и общую блокировку модели; LM Studio обслуживает существующую Qwen3.5-9B. Прямого доступа браузера к worker нет.
- Python оценивается автоматически с записью балла/прогресса. Активен `evidence-v3e-context`, четыре упражнения; `/assess/receipt` не означает готовое восстановление оценки в Django.
- Личные TXT/PDF/DOCX/PPTX → выбранный фрагмент → мини-курс/MCQ → попытка → баллы и отдельный прогресс. Любые учебные темы разрешены; свободные эссе по всем темам не реализованы. В MCQ модель создаёт ключ, сервер сверяет выбор с ключом.
- Обязательный преподаватель исключён владельцем. Старые T01/teacher gate — история.
- UX01: ровные кликабельные строки; выбранный/верный ответ и объяснение; цитата свёрнута отдельно; Python-отчёт разделён на балл, «Зачтено» и «Нужно уточнить».
- Новая подсказка исключает один неверный вариант с причиной, оставляя три. Объяснение привязано к тексту варианта. При провале проверки подсказка недоступна. Старые материалы не переписываются, попытки сохраняются.
- Учебный пакет из 61 файла отложен. Платный API, новые веса и RAG не добавлялись. Профиль другого ПК 60/70/80 и эксперимент SDK load/abort не активированы.

## Именование

| Назначение | Единая форма |
| --- | --- |
| Отображаемое имя | LAT AI |
| Имя с расшифровкой | LAT AI — LEARN AND TALK |
| Slug: файлы, архивы, пакеты, email, ключи | `lat-ai` |
| snake_case: БД и Python-идентификаторы | `lat_ai` |
| Префикс переменных окружения | `LAT_`: `LAT_AI_RUNTIME`, `LAT_FRONTEND_PORT`, `LAT_MODEL_KEY` |
| HTTP-заголовок IPC | `X-LAT-IPC` |
| Синтетический тестовый аккаунт | `review@lat-ai.local` / `LatAI-Review-2026!` |
| Имя пакетного архива (фиксированный формат релиза) | `LAT-AI-Document-Pilot` |
| Отображаемое имя релиза | `LAT AI document pilot …` |
| Значения БД по умолчанию | `lat_ai` (имя, пользователь и пароль локального примера) |

Перед обновлением остановите старый воркер штатным способом и обновите постоянные переменные окружения Windows до префикса `LAT_`; fallback на прежние имена отсутствует. Для существующей БД явно укажите `DB_NAME`, `DB_USER` и `DB_PASSWORD` в локальном `.env`. Переименование исходников не переименовывает БД или пользователей и не изменяет runtime, секреты и квитанции.

Готовый тестовый профиль с `seed.json` сохраняет прежний аккаунт, курс и mapping. Новый профиль получает новые имена; digest курса вычисляется вместе с mapping. Не переименовывайте существующий курс вручную без согласованного обновления mapping. Если в БД нет маркера `seed.json`, подготовка создаёт синтетические записи заново: рядом со старым аккаунтом может появиться второй пользователь и курс; это не миграция существующих данных.

Исторические документы, доказательства проверки, eval JSON, существующие миграции, замороженное ядро и внешние пути происхождения сохраняются дословно. Имена модулей, команды запуска, JS-глобалы и существующие ключи localStorage не переименовываются.
